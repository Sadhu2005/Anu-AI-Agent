## Live expand note (LM Studio tool-JSON)

plan JSON, e.g.:

```text
{"name": "create_plan", "parameters": {"plan": "..."}}
```

`improve_sandbox` (`source=template_fallback`, 6 tasks). This satisfies the
exit criterion: gateway-up expand may use `source=llm` **or** documented
template fallback when the model returns a tool-JSON quirk.
