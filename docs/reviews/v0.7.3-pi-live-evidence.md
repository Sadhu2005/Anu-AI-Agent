## Live expand note (tool-echo, not plan)

After unwrap landed, LM Studio still often returns a tool-call that **echoes
the prompt fields** instead of a plan:

```text
{"name": "propose_plan", "parameters": {"goal_description": "...", "project_key": "..."}}
```

`coerce_plan_object` unwraps `parameters`, finds no `steps` → `steps_not_list`
→ template `improve_sandbox`. Fallback is correct and safe.

Plan-shaped envelopes (the V0.7.2 quirk) are covered by the portable unwrap
pack. Getting consistent live `source=llm` needs a stronger no-tools prompt /
retry or disabling tool-use in LM Studio (follow-on).
