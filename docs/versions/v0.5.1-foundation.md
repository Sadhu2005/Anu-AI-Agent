## Goal

Build a safe execution substrate on the Raspberry Pi before any agent logic:
ANU may only touch projects through controlled, checkpointed, allow-listed paths.

## What Was Built

| Component | File | Purpose |
|---|---|---|
| Runtime | `bin/anu-runtime.py` | Long-lived service loop with health checks and state file |
| Resource Guardian | `bin/anu-resource-guardian.py` | RAM / disk / CPU / temperature status |
| Resource Governor | `bin/anu-resource-governor.py` | ANU budgets and admission |
| Command Gateway | `bin/anu-command-gateway.py` | Allow-listed named commands only (e.g. `git_status`, `python_test`) |
| Executor | `bin/anu-executor.py` | Runs commands under execution profiles (RAM, timeout, output caps) |
| Execution profiles | `bin/anu-execution-profile.py` | `inspect`, `git-read`, `python-basic`, `system-info`, `python-sandbox` |
| Sandbox daemon | `bin/anu-sandboxd.py`, `bin/anu-sandbox-client.py` | Docker-isolated execution, no network |
| Result normalizer | `bin/anu-result-normalizer.py` | Uniform result shape from command output |
| Safe Mutation v0.1 / v0.2 | `bin/anu-safe-mutation.py`, `bin/anu-safe-mutation-v0.2.py` | Checkpoint → apply → verify → commit / rollback |
| Execution context | `bin/anu-execution-context-v0.5.1.py` | Carries task/run/attempt context into mutation |
| Task Engine v0.3 → v0.5.1 | `bin/anu-task-engine-v0.3.py` … `-v0.5.1.py` | Task lifecycle, then explicit retry semantics |

## Key Design Decisions

- The Task Engine **never** runs raw shell commands against a project; all
  changes go through Safe Mutation.
- A retry must supply a **new** mutation plan; failed plans are never blindly re-run.
- `blocked` tasks are not auto-retried (cause may be environmental or policy).
- Maximum 3 attempts per task.
