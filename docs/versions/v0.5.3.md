## Goal

Tasks can depend on other tasks; a task is only admitted for execution when
its prerequisites are satisfied.

## Design

- Task graph evaluates each task as `READY` (dependencies satisfied) or
  `WAITING` (dependencies outstanding).
- The task engine refuses to start a task whose admission state is not `READY`.
- All policy configuration was brought under version control in `config/`:
  admission policy, command gateway, execution profiles, executor, policy,
  projects, resources, runtime, sandbox.
