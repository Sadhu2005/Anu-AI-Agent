## Goal

Introduce a scheduler that discovers runnable tasks, decides which to WAKE,
knows *how* to execute each task (execution specification), and dispatches a
bounded production cycle.

## Design

- `discover_ready_tasks()` finds candidates; `build_ready_task_wake_plan()`
  maps `READY → WAKE`, `WAITING → WAIT`.
- When a task completes, `build_dependency_wake_plan()` finds dependants that
  can now wake.
- **Execution specification**: each task stores a descriptor (project,
  changes file, operation) so the scheduler can execute it without guessing.
- Production cycle is **bounded** (`max_tasks`) so one tick cannot run away.
