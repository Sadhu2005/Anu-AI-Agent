## Goal

A real autonomous agent cannot assume every task finishes immediately.
WAITING must be a resumable state, not a terminal one.

## Design

```text
OBSERVING
    ↓
WAITING
    ↓
future condition / event
    ↓
wake
    ↓
continue execution
```
