## Goal

Make the scheduler wake the **agent**, not the generic Task Engine.

## Design

Before:

```text
Scheduler → generic Task Engine
```

After:

```text
Scheduler
   ↓
Agent-aware scheduler lifecycle
   ↓
Agent execution runtime
   ↓
AgentController
   ↓
Task Engine
```

New scheduler entry points: `run_agent_scheduler_cycle_once()`,
`run_production_agent_scheduler_cycle()`,
`build_production_agent_wake_execution_handler()`.
