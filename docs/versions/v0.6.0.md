# ANU V0.6.0 — Reliable Autonomous Execution

| | |
|---|---|
| **Status** | Planned |
| **Branch** | `v0.6.0-integration` |
| **Depends on** | V0.5.9 frozen |

## Goal

Once a single autonomous execution works, make it **reliable** before making
ANU smarter.

> **Critical requirement:** if the Raspberry Pi reboots halfway through a
> mutation, ANU must not blindly execute the same mutation again.

## Scope

In scope:

- Retry limits and **retry classification** (transient vs code defect vs
  policy/environment) on top of the existing `MAX_ATTEMPTS = 3`
- Stale-`running` task detection (heartbeat / lease expiry)
- Crash recovery and restart recovery
- Scheduler lock recovery (stale `runtime/anu-scheduler.lock`)
- Idempotency keys for mutations
- Mutation transaction recovery (in-flight transactions resolved on start)
- Checkpoint recovery (restore or verify on start)

Out of scope: planning, new capabilities, memory.

## Design

```text
Task → Attempt 1 → FAILED → classify → retry policy → Attempt 2 … (max N)
                               └─ non-retryable → BLOCKED with reason
```

- Every mutation gets an **idempotency key** derived from task, attempt and
  change set; a key that already reached `COMMITTED` is never applied again.
- Transaction journal states: `PREPARED → CHECKPOINTED → APPLIED → VERIFIED → COMMITTED | ROLLED_BACK`.
  On start-up, anything not terminal is reconciled against the checkpoint.
- Running tasks hold a **lease** (owner PID, expiry). Expired leases mark the
  task stale and send it to recovery, not straight to re-execution.
- The scheduler lock records PID and timestamp; a lock whose PID is dead is reclaimed.

## Exit Criteria

- [ ] Killing the runtime mid-mutation, then restarting, never double-applies a change
- [ ] In-flight transactions are reconciled to COMMITTED or ROLLED_BACK on restart
- [ ] Stale locks and stale running tasks recover automatically
- [ ] Retries happen only for retryable classes and stop at the limit
- [ ] Real `systemctl restart` and Pi reboot test performed with evidence
