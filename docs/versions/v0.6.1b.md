## Goal

Close host and Brain boundary gaps from the 16 Oct 2026 Claude review **before**
capability invoke exposes git on the host. No new product features — harden
paths, SQLite, audit, sandbox, and host git.

## Design Notes

- **F3:** All mutation file and changes-file resolution goes through
  `resolve_project` / `resolve_file` / `resolve_changes_file`; forbidden
  segments include `.git` and traversal outside the project root.
- **F4:** Host git commands run with minimal env (`GIT_CONFIG_NOSYSTEM`,
  `GIT_CONFIG_GLOBAL=/dev/null`) and injected `-c core.fsmonitor=false`,
  `-c core.hooksPath=/dev/null`, plus diff hardening flags where applicable.
- **F7 / F8:** Brain modules should open SQLite via `db_connect`; failed
  `agent_events` inserts increment `DROPPED_EVENTS` and log
  `ANU_DROPPED_EVENT` on stderr instead of failing silently.
- **F12:** Sandbox runs use `docker run --pull never`; request handling and
  cleanup tolerate leftover `anu-sbx-*` containers.
