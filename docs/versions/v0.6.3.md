## Goal

ANU accumulates **operational knowledge** that improves later decisions.

```text
Observation → Interpretation → Memory → Future decision
```

## Example

```text
Task failed because dependency missing
            ↓
store observation
            ↓
future planner recognises similar situation
```

## Scope

- Builds on existing DB tables: `observations`, `research`, `errors`,
  `agent_events`, `resource_usage`
- Additive `agent_memories` (provenance, confidence, expiry) —
  `migrations/0006_v0_6_3.sql`
- Structured observation records from capability results (via adapter)
- Interpretation: classify/tag (project, capability, failure class)
- Retrieval API for the template planner when expanding a goal
- Bounded size + TTL expiry / prune

Out of scope: vector search or model-based summarisation.
