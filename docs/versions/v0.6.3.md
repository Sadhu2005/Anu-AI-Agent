|---|---|

## Goal

ANU accumulates **operational knowledge** that improves later decisions.

```text
Observation → Interpretation → Memory → Future decision
```

## Example

```text
Task failed because dependency missing
            ↓
store observation
            ↓
future planner recognises similar situation
```

## Scope

- Builds on existing DB tables: `observations`, `research`, `errors`,
  `agent_events`, `resource_usage`
- Structured observation records from every capability result (V0.6.2)
- Interpretation step: classify and tag observations (project, capability,
  failure class)
- Memory records with provenance (which task/observation created them),
  confidence, and expiry
- Retrieval API used by the planner (V0.6.1) when building a plan

Out of scope: vector search or model-based summarisation (may come later, gated by resources).

- [ ] A repeated failure is recognised from memory and changes the plan
- [ ] Every memory item traces back to its source observation
- [ ] Memory size is bounded and stale items expire
