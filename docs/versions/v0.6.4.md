## Goal

ANU understands projects instead of treating them as arbitrary directories.

## Project Model

```text
Project
 ├── identity
 ├── purpose
 ├── files
 ├── tests
 ├── dependencies
 ├── current state
 ├── history
 └── known problems
```

## Scope

- Single source of truth for project registration. Today
  `config/anu-projects.yaml` has `projects: []` while
  `workspace/projects/sandbox-test-project` exists; resolve this first.
- Project scanner (read-only capabilities) that builds and refreshes the model
- Known problems linked to memory (V0.6.3)
- Planner reads project state when building plans (V0.6.1)
- Existing rules kept: explicit registration, one repository per project,
  production deployment requires approval

## Tests (proposed)

- `test_project_registration_v0_6_4.py`

## Exit Criteria

- [ ] Registered projects have a complete, refreshed model
- [ ] Unregistered directories are never mutated
- [ ] Planner decisions reference project state
