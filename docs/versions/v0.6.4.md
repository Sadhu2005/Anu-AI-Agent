## Goal

ANU understands projects instead of treating them as arbitrary directories.

## Project Model

```text
Project
 ├── identity
 ├── purpose
 ├── files
 ├── tests
 ├── dependencies
 ├── current state
 ├── history
 └── known problems
```

## Scope

- Single source of truth for project registration:
  `config/anu-projects.yaml` (allow-list) + Brain `projects` row
- Project scanner (read-only) builds/refreshes `project_models`
- Known problems linked to memory (V0.6.3)
- Planner reads project state when building plans; unregistered denied
- Safe Mutation refuses unregistered projects when registration required
- Rules kept: explicit registration, one repository per project,
  production deployment requires approval
