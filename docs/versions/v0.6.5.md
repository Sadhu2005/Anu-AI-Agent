## Goal

An autonomous system cannot merely say "I changed the code". It must prove it.

```text
PLAN → EXECUTE → OBSERVE → VERIFY → ACCEPT | RETRY | ROLLBACK
```

## Verification Questions

- Did it compile?
- Did tests pass?
- Did the intended file change?
- Did unintended files change?
- Did the checkpoint match?
- Did rollback work?
- Did the final state satisfy the goal?

## Scope

- Verification record per task attempt, answering each question with evidence
- Diff-scope check: changed files ⊆ declared change set
- Checkpoint integrity check before and after mutation
- Goal-level acceptance check (V0.6.1) on top of task-level checks
- Decision output feeds V0.6.0 retry policy

## Exit Criteria

- [ ] No task reaches COMPLETE without a passing verification record
- [ ] Unintended file changes trigger ROLLBACK
- [ ] Verification decisions are persisted and auditable
