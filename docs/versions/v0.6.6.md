## Goal

ANU chooses work based on machine conditions, not just a single NORMAL /
not-NORMAL gate.

```text
RAM low                 → don't start heavy task
temperature high        → WAIT
disk low                → DENY
one task already running → queue next task
```

## Scope

- **Single source of resource policy.** `config/anu-resources.yaml` is
  authoritative via `anu-resource-policy-v0.1.py`. Guardian, Governor and
  Task Engine read limits from it (including `MAX_ATTEMPTS`). Consistency
  gate checks admission + policy YAML stay aligned (SECURITY G5).
- **Temperature hysteresis:** resume only below `resume_celsius` (55 °C).
- Per-task admission: RUN / WAIT / DENY (heavy RAM, hot host, low disk)
- Heavy-workload thresholds used in scheduling
- Production services keep priority (`production.priority: highest`)
