## Goal

ANU should not need humans for normal work, but risky operations stop and ask.

```text
AUTONOMOUS          when safe
HUMAN-IN-THE-LOOP   when risky
DENY                when unsafe
```

## Classification

| Situation | Decision |
|---|---|
| Normal file < 250 MB | Automatic |
| Large file (up to 2048 MB) | Approval |
| Dangerous operation | Deny / Approval per action table |
| Unknown resource | Deny |
| Major project mutation | Approval |
| Production-impacting action | Approval |

## Scope

- Approval request record (what, why, risk, proposed change, expiry)
- Task enters WAITING; approve resumes to pending
- CLI channel (request / list / approve / reject / expire)
- Approved / rejected / expired outcomes audited
