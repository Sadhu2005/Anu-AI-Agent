## Goal

ANU becomes a durable service rather than a task runner.

It must survive: reboot, process crash, temporary failure, waiting, network
recovery, partial execution, and resume from durable state.

```text
ANU START → load state → find incomplete goals/tasks → recover → continue
```

## Scope

- Startup recovery sequence covering goals, plans, tasks, transactions,
  approvals, and WAITING conditions
- Durable wake conditions (time, dependency, approval, resource) evaluated after restart
- Graceful shutdown: finish or safely park the current step on SIGTERM
- Health/heartbeat reporting in `runtime/anu-state.json`
- Log rotation for `logs/*.jsonl` (`anu-mutations.jsonl` is already ~5 MB)
