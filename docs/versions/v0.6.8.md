## Goal

ANU becomes a durable service rather than a task runner.

```text
ANU START → load state → find incomplete goals/tasks → recover → continue
```

## Scope

- Startup recovery sequence covering goals, plans, tasks, transactions,
  approvals, and WAITING conditions
- Durable wake conditions (time, dependency, approval, resource)
- Graceful shutdown: park state on SIGTERM
- Health/heartbeat in `runtime/anu-state.json`
- Log rotation for oversized `logs/*.jsonl`
