## Goal

## Target Architecture

```text
GOAL → PLANNER → TASK GRAPH → SCHEDULER → CONTROLLER → TOOLS
  → EXECUTION → OBSERVATION → VERIFICATION → COMPLETE|RETRY
  → MEMORY → NEXT GOAL
```

Underneath: Resource Governor · Security Policy · Checkpoints · DB ·
Audit · Recovery · Human Approval.

## Exit Criteria

- [ ] A high-level goal on a registered project is planned, executed,
      verified, and remembered with no human input when safe
- [ ] A risky step pauses for approval and resumes
- [ ] A reboot mid-goal recovers without duplicated work
- [ ] Resource pressure defers work and resumes it
- [ ] Full regression V0.5.1 → V0.7.0 passes
- [ ] Tagged `v0.7.0`, documented with evidence

Portable packs cover the above in-repo; Pi must demonstrate them live.
