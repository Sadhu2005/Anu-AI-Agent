## Goal

Give ANU a **replaceable intelligence provider** without giving the agent
general network access or rewriting the runtime.

```text
anu-agent (PrivateNetwork)
    │  Unix socket + SO_PEERCRED
    ▼
anu-model-gateway.service
    │  LAN / HTTPS
    ▼
OpenAI-compatible API (LM Studio on PC, or cloud)
```

**Switching providers** = change config (`base_url`, `model`) and the API key
credential. Protocol stays the same.

## Delivered (step 2)

| Artefact | Role |
|---|---|
| `anu-model-gateway-v0.1.py serve` | AF_UNIX listener |
| `anu-model-client-v0.1.py` | Agent-side caller |
| `deploy/systemd/anu-model-gateway.service` | Hardened unit + credential |
| Config `socket.*` | path, mode, require_peercred, allow_user/group |

Pi operator: set `base_url` to `http://192.168.1.13:1234/v1` (PC LAN), install
key under `/etc/anu/model-api-key`, enable the unit. See
[MODEL-GATEWAY.md](../MODEL-GATEWAY.md).
