## Goal

Use the model gateway to **propose** a goal plan when healthy, with automatic
fallback to the V0.7.0 `improve_sandbox` template when the gateway is down or
the model returns invalid output.

## Scope

**In**
- LLM step proposal via Unix-socket client → gateway
- Strict validation: only `python_test` / `python_compile`
- Template fallback; config `planner.mode`
- Wire into goal-cycle expand path

**Out**
- New Safe Mutation operations
- LLM replan in goal-recovery (stays template)
- Budget ledger / local-on-Pi models
