workspace project is not its own git root (status walks up to `/srv/anu`).

## Behaviour

- Host git always gets `-c safe.directory=*` (plus project + `ANU_BASE`).
- If the project directory has no `.git`, mutation does not call
  `git_status_short` — `actual_changed_files=None` remains scope-OK.
- Paths containing `..` are rejected the same way.
