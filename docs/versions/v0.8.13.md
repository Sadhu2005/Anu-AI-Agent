## Behaviour

```text
python3 bin/anu-project-assign-v0.1.py connect \
  --github Sadhu2005/my-todo \
  --goal "Add a simple todo list"
```

- Owner must be in `anu-github.yaml` `allow_owners`.
- SSH / non-github hosts / HTTP are rejected.
- Existing workspace keys can be assigned without clone (`--project-key` + `--no-clone`).
- `--expand` is optional; default is register + pending goal only.
