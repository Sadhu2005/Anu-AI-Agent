## Goal

After a stage completes successfully, automatically start the next READY
dependent (one successor per completion; chain capped) so multi-stage goals
do not need a manual `run` between stages.

## Behaviour

- On success (`ok` + `task_status=completed`), pick highest-priority pending
  dependent whose Task Graph admission is READY and that has an execution spec.
- Start it via `start_task(..., _chain_depth=n+1)` outside the execution lock.
- Cap: `MAX_AUTO_ADVANCE_CHAIN = 8`.
- If the next stage needs approval, it parks `waiting` (same as a manual run).
- Emit `TASK_AUTO_ADVANCE` on the completed task.
