## Goal

Persistent objective, checklist, `AUTONOMY_PROGRESS.md`, agent control, and a
controller that decides CONTINUE / REPLAN / PAUSE_FOR_USER / COMPLETE with
loop guards — the foundation for junior-dev autonomy.

## Scope

- In scope: schema migration `0011_v0_9_0`, autonomy state helpers, controller,
  runtime wiring, assign `--autonomous` / `--objective` / `--criteria`,
  progress file, regression pack.
- Out of scope (later V0.9.x): full multi-LLM proof on live keys, dashboard UI
  polish screenshots, production push of sandbox to GitHub without credentials.

## Design

See [AUTONOMY.md](../AUTONOMY.md) and the V0.9 plan. Safety order unchanged:
Safety → Control → Recovery → Observability → Autonomy → Capability.
