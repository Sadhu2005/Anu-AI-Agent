## Goal

Rework the ANU dashboard into a tabbed operator console, fix empty/broken panel bindings, and document remaining capability gaps (UI and agent) that are not built in this version.

## Scope

**In scope**

- Tabbed SPA (Overview / Active Goal / Runtime / Approvals / Assign) in `bin/anu-dashboard-v0.1.py`
- Keep System gauges as-is
- Fix checklist binding (`goal.checklist`), goal select from `GET /api/goals`, approval labels, empty states, heartbeat age
- Small API polish: slim goals list, progress excerpt, approval `label`
- Docs: this note + AUTONOMY / PI-OPS tab map + missing backlog

**Out of scope**

- Vite/React split, LAN exposure, System gauge redesign
- Mutation diff viewer, task-graph viz, checkpoint restore UI, SSE, login page (listed below)

## UI tabs

| Tab | Contents |
|---|---|
| Overview | System gauges, goals table, current tasks, stale-heartbeat banner |
| Active Goal | Selector (header), objective, checklist+evidence, task timeline, progress excerpt, message form |
| Runtime | Events, taller logs, LLM providers, Git + Tests |
| Approvals | Pending inbox Approve/Deny |
| Assign | New goal form (`project_key`, description, objective, criteria, autonomous) |

Sticky header: Pause / Resume / Stop + goal select. Tab state in `location.hash`. CSRF via `X-ANU-Token`; bind `127.0.0.1` only.

## Missing features backlog (not built in 0.9.10)

### Dashboard gaps

- Mutation diff viewer
- Task-graph visualization
- Checkpoint restore button
- Clearer per-goal pause (vs global control)
- Login page instead of `prompt()` for token
- SSE / push instead of 3s poll
- Checklist evidence as clickable links

### Agent gaps

- Stronger multi-file change generator
- Env bootstrap stage
- Architecture stage
- Broader test matrix
- Debug artifacts surfaced in UI
- Gated PR creation from UI
- Deploy remains denied by policy (intentional)
