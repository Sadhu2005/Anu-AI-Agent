## Goal

Make the existing ANU autonomy lifecycle trustworthy before introducing Hermes:
real spend accounting, CI coverage through V0.9.15, a genuine scheduler→git lab
acceptance path, and documentation that matches live Pi network/push behaviour.

## Scope

- In scope: LLM usage USD accounting; CI packs V0.9.1–V0.9.15; lab E2E with real
  matrix + push evidence; docs/network reconcile (`PrivateNetwork`,
  `push_after_accept`, README drift).
- Out of scope: Hermes install, adapter code, Podman worker, gateway tool-call
  proxy.

## Design

ANU remains the only writer of brain state and git. Hardening proves:

```text
Assign → expand → implement/test/verify → ACCEPT
  → matrix → commit agent/* → push (when token present)
  → gated PR payload (human only)
```

Fix router usage so `max_usd_per_day` can enforce non-zero cloud spend.
Do not treat matrix `SKIPPED` layers as proof that every category ran.
