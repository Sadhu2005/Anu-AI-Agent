## Goal

Prove Hermes CLI runs on ARM64 with a ≥64K-context, tool-capable model in
**isolation** — no ANU workspace, secrets, or brain access yet.

## Scope

- In scope: Hermes install (version-pinned); OpenRouter and LM Studio smoke
  tests separately; blank-slate / minimal toolset; experiment branch docs.
- Out of scope: Podman production workspace (V1.3); ANU adapter (V1.4);
  Safe Mutation handoff (V1.5); git push from Hermes; installing LM Studio on
  the PC (operator provides that service).

## Design

```text
experiment/hermes-worker
  └── Hermes CLI only
        ├── provider: LM Studio (LAN) OR OpenRouter
        ├── tools: blank slate (minimal)
        ├── disable: subagents, cron, browser, messaging
        └── no mount of /srv/anu
```

Do **not** point Hermes at ANU's Unix model gateway expecting tool calls to
work. Configure Hermes providers per official docs.
