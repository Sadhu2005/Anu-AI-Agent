## Goal

Give Hermes a **safe temporary coding environment** on the Pi: dedicated user,
rootless Podman, resource limits, no network inside the code container, and no
privileged Docker socket.

## Scope

- In scope: `anu-hermes` (or equivalent) non-root user; rootless Podman;
  ephemeral project snapshot workspace; cgroup/memory/CPU limits;
  `terminal.docker_network: false` (or equivalent) for execution.
- Out of scope: ANU adapter job API (V1.4); applying patches via Safe Mutation
  (V1.5); granting GitHub push credentials to Hermes.

## Design

```text
anu-hermes (non-root)
  └── Hermes host process
        ├── may call LM Studio / OpenRouter (host network — separate concern)
        └── rootless Podman container for terminal/code
              ├── project snapshot only (RW temp copy)
              ├── network: none
              ├── no /srv/anu/secrets
              └── no Docker privileged socket
```

ANU verification sandbox (`anu-sandbox.yaml` RO) stays unchanged for
independent tests. Hermes never writes the production checkout in place.
