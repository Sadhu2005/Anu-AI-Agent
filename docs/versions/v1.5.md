## Goal

Import a Hermes-proposed patch into ANU's existing verification path: validate,
convert to `file/old/new`, Safe Mutation, independent test matrix, diagnose /
repair within budget — Hermes never bypasses these gates.

## Scope

- In scope: change validator (paths, secrets, protected paths, size limits);
  conversion to mutation format; Safe Mutation apply; matrix +
  `anu-failure-diagnose`; human approval class for Hermes-sourced changes;
  rollback on failure; no git push from Hermes.
- Out of scope: gated PR UI polish and Hermes dashboard (V1.6); auto-merge;
  production deploy.

## Design

```text
Hermes result
  → base_commit still matches project tip (or abort)
  → path / symlink / delete / secret / protected-path checks
  → file/old/new mutation doc
  → Safe Mutation: checkpoint → apply → verify
  → Test matrix (ANU sandbox; independent of Hermes claims)
  → PASS: eligible for git stage (ANU-owned)
  → FAIL: DIAGNOSIS → REPLAN/repair budget → no push
```

Hermes `test_summary` is advisory only. ANU matrix exit codes are authoritative.
Required layers for lab projects must be configured so `SKIPPED` is not confused
with pass.

## Tests

| Experiment | Expected |
|---|---|
| Build small Python utility via Hermes | Real files; ANU matrix PASS |
| Add unit tests | Independent pass |
| Inject bug | Diagnose + repair proposal within budget |
| Malicious repo instructions | No unauthorized capability |
| Secrets path / container egress | Denied (regression from V1.3) |
| Model outage | Pause / configured fallback |
| Kill worker mid-task | No duplicate mutation |
| Fail verification | Rollback; no `GIT_PUSH_OK` |
| Pass verification | Eligible for ANU-owned commit step |

## Exit Criteria

- [ ] Hermes patch cannot skip Safe Mutation
- [ ] Independent matrix must pass before any ANU commit/push
- [ ] Failure writes diagnosis and stays within retry budget
- [ ] Rollback leaves tree consistent; no agent branch tip advanced on fail
- [ ] Acceptance table above covered by automated and/or Pi evidence
