## Goal

Close the loop: after ANU verifies a Hermes-sourced change, use the existing
`agent/*` git workflow, gated PR payload, CI evidence, and **human merge** —
with dashboard visibility into Hermes jobs.

## Scope

- In scope: post-ACCEPT git for Hermes-verified slices; gated PR (never
  auto-merge); CI checks on `agent/*`; dashboard panel/API for Hermes job
  status; operator docs.
- Out of scope: auto-merge; production deploy; force-push; Hermes owning git
  credentials; rewriting ANU in TypeScript.

## Design

```text
V1.5 ACCEPT
  → ANU git workflow: agent/<goal>-… commit
  → push agent/* (ANU token / ANU_GITHUB_TOKEN_FILE only)
  → create_pr_gated payload (human authorize)
  → CI on PR
  → human merge to default branch
```

Dashboard shows: job_id, Hermes status, changed files count, matrix summary,
link to branch/PR. Control plane pause/resume/delete remain ANU-owned.
